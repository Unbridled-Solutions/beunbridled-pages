Six pillars of protection

A managed AI agent touches sensitive business context daily. Here's how we think about keeping it safe.

🏠

Dedicated Infrastructure

  • Your own private VPS — not shared with other clients
  • Hosted in a Tier 1 data center (Ashburn, VA)
  • ISO 27001-certified facility
  • No multi-tenant risk — your memory stays your memory
🔐

Access Control

  • SSH key authentication only — no password logins
  • Root access disabled by default
  • Firewall default-deny — only required ports open
  • Principle of least privilege throughout
🛡️

Threat Detection

  • Industry-standard intrusion prevention (active 24/7)
  • Automatic blocking of suspicious access patterns
  • Critical OS security patches applied automatically
  • Gateway health monitored — alerts fire within 5 minutes
🤖

AI and Data Privacy

  • Your data is never used to train AI models
  • API inference is stateless at the provider level
  • Legal/sensitive tasks routed through zero-retention AI
  • Session memory lives on your server — under your control
🔑

Credentials and Keys

  • All keys stored in permission-locked environment files
  • Never stored in source code or transmitted in plaintext
  • Credentials scoped to minimum required permissions
  • You own your Telegram bot — we never retain the token
💾

Backup and Recovery

  • Daily encrypted backups to Backblaze B2 object storage
  • AES-256 encryption at rest — 30-day retention
  • Full recovery possible from any server incident
  • Weekly full-system snapshots, independent of daily Hermes backups
Infrastructure
Your server. Your context. Nobody else's.

Every BeUnbridled client receives their own dedicated virtual private server — not a slice of a shared pool. Your agent's knowledge, your conversations, and your business context live in an isolated environment. There is no multi-tenant risk.

Our hosting provider operates ISO 27001-certified data centers with 24/7 physical security, redundant power, and enterprise network infrastructure. Data is stored in the United States.

Access Control
Brute-force attacks aren't possible. By design.

Your server does not accept password-based logins — at all. All access requires cryptographic SSH key authentication. Brute-force attacks are structurally impossible because passwords are not accepted.

Direct root access is disabled. Administrative operations use a named user account with tightly scoped elevated permissions. The agent process runs with only what it needs — nothing more.

All inbound traffic is blocked by default. Only the ports required for your agent to function are open.

AI Privacy
Your conversations don't train anyone's models.

We route AI inference through OpenRouter to leading model providers (Anthropic Claude, Google Gemini, etc.) under API agreements that explicitly prohibit use of API traffic for model training. Your queries are processed and returned — not stored, not learned from.

Session memory lives on your dedicated server, under your control. For legal, M&A, or otherwise sensitive tasks, we route through a zero-retention inference provider where no request logs are kept — not even temporarily.
